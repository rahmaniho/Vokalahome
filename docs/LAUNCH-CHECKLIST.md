## بخش ۲ — آزمون محلی

```bash
npm run build && npm run preview
# باز کنید: http://localhost:4173/Vokalahome/
```

> `npm run preview` عمداً زیرمسیر GitHub Pages را شبیه‌سازی می‌کند. `npx serve out`
> این کار را نمی‌کند و باگ‌های مسیر را پنهان می‌کند.

## بخش ۳ — دسترسی‌پذیری

### ۳٫۱ صفحه‌کلید

- [ ] فقط با Tab می‌شود کل سایت را پیمود
- [ ] حلقهٔ فوکوس روی همهٔ عناصر دیده می‌شود
- [ ] ترتیب Tab منطقی است (راست به چپ، بالا به پایین)
- [ ] Skip link با اولین Tab ظاهر می‌شود
- [ ] مودال: فوکوس داخلش گیر می‌افتد، با Esc بسته می‌شود، فوکوس برمی‌گردد
- [ ] منوی موبایل با صفحه‌کلید هم باز و بسته می‌شود
- [ ] لایت‌باکس با کلید جهت‌نما و Esc

### ۳٫۲ صفحه‌خوان

با NVDA (ویندوز) یا VoiceOver (مک/iOS):

- [ ] عنوان صفحه خوانده می‌شود
- [ ] ساختار عنوان‌ها منطقی است (یک `h1`، سپس `h2` و `h3`)
- [ ] تصاویر `alt` توصیفی دارند
- [ ] دکمه‌های فقط‌آیکون نام قابل دسترس دارند
- [ ] خطاهای فرم اعلام می‌شوند
- [ ] وضعیت باز/بسته منو اعلام می‌شود (`aria-expanded`)

### ۳٫۳ سایر

- [ ] با `prefers-reduced-motion: reduce` هیچ انیمیشنی اجرا نمی‌شود
- [ ] با بزرگ‌نمایی ۲۰۰٪ محتوا قابل خواندن است
- [ ] هیچ اطلاعاتی فقط با رنگ منتقل نمی‌شود
- [ ] کنتراست متن‌ها حداقل AA است

> ابزار سریع: افزونهٔ [axe DevTools](https://www.deque.com/axe/devtools/) یا
> بخش Accessibility در Lighthouse.
