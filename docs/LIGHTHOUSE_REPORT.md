## ⚠️ چرا «قبل» عدد Performance بالاتری دارد؟ (این گمراه‌کننده است)

بررسی audit خام `network-requests` نشان داد نسخهٔ زندهٔ فعلی سایت **۳ درخواست
۴۰۴ واقعی** دارد:

- `hero/lawyers-cafe.jpg` (تصویر اصلی هیرو)
- `cafe/coffee-and-case.jpg`
- `favicon.svg`

یعنی تصویر هیرو و آیکون سایت اصلاً روی سایت زندهٔ فعلی بارگذاری نمی‌شوند —
Lighthouse چیزی برای رندر/صبرکردن ندارد، پس LCP مصنوعاً خیلی سریع (۰.۸ ثانیه)
و امتیاز Performance مصنوعاً بالا (۹۹) محاسبه می‌شود. **این امتیاز بالاتر
نشانهٔ سایت بهتر نیست؛ نشانهٔ سایت شکسته‌تر است.**

در نسخهٔ رفع‌شده، باگ basePath تصاویر (`asset()` در `src/lib/basePath.ts`)
برطرف شد؛ حالا تصویر واقعی هیرو بارگذاری و رندر می‌شود، به همین دلیل LCP به
۲.۳ ثانیه افزایش یافته — چون این بار واقعاً منتظر بارگذاری و رندر یک تصویر
واقعی می‌ماند، نه یک placeholder خالی. معیار موفقیت واقعی این پروژه **صفر
شدن تعداد ۴۰۴ها** است، نه عدد خام Performance.

## چرا مقایسه کاملاً «برابر» نیست (و چرا عدد بعد بهتر هم می‌شود)

نسخهٔ «بعد» با `python -m http.server` تست شده — یک سرور استاتیک بسیار ساده
بدون HTTP/2، بدون فشرده‌سازی gzip/brotli، و بدون هدر `Cache-Control`. نسخهٔ
«قبل» از CDN واقعی GitHub Pages (Fastly) با HTTP/2، فشرده‌سازی و کش سرو
می‌شود. انتظار می‌رود پس از deploy واقعی نسخهٔ رفع‌شده روی GitHub Pages
(همان CDN)، عدد Performance به‌طور محسوس از ۸۸ فراتر برود، در حالی که صفر
درخواست ۴۰۴ و امتیازهای ۱۰۰/۱۰۰/۱۰۰ در Accessibility/Best Practices/SEO حفظ
می‌مانند.

## بهبودهای Accessibility (۹۲ → ۱۰۰) به تفکیک

بررسی دقیق‌تر مشخص کرد **پالت طلایی برند (`#C9A227`) روی زمینهٔ روشن (`#F5F6F8`)
تنها کنتراست ۲.۲۳:۱ دارد** — به‌طور قابل‌توجهی پایین‌تر از حداقل استاندارد
WCAG AA (۴.۵:۱ برای متن معمولی، ۳:۱ برای متن بزرگ ضخیم). این یعنی طراحی اولیهٔ
پالت برای استفاده به‌عنوان رنگ متن روی زمینهٔ روشن مناسب نبود. رفع شد با:

- افزودن نسخهٔ تیره‌تر طلایی (`#7A611A` برای متن کوچک، `#96791D` برای تیترهای بزرگ) که فقط روی زمینهٔ روشن استفاده می‌شود؛ طلایی روشن اصلی (`#C9A227`) برای دکمه‌ها، آیکون‌ها و متن روی زمینهٔ تیره (که کنتراست کافی دارد) بدون تغییر باقی ماند.
- افزایش سایز ناحیهٔ لمسی دکمه‌های اسلایدر نظرات از ۸×۸px به ۲۴×۲۴px.
- افزایش opacity چند متن کم‌رنگ (فوتر، برچسب‌های کوچک) که کنتراست مرزی داشتند.

نتیجه: صفر مشکل کنتراست باقی‌مانده، صفر مشکل اندازهٔ هدف لمسی.

## گزارش‌های خام
فایل‌های کامل JSON/HTML این اجراها (خارج از مخزن، در محیط توسعه تولید شدند):
`lighthouse-before.report.{json,html}` و `lighthouse-after.report.{json,html}`.
برای بازتولید:

```bash
npm run build
npx serve out -p 8080   # یا هر سرور استاتیک دیگر
npx lighthouse http://localhost:8080/Vokalahome/ --preset=desktop --view
```
