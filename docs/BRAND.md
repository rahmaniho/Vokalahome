## ۱. نشانه (لوگو)

### ایده

سه چیز در یک فرم ادغام شده‌اند، بدون آنکه هیچ‌کدام جدا به نظر برسند:

| عنصر | چه می‌گوید |
| --- | --- |
| **خانه** — بام شیب‌دار و دیوارها | «خانه» وکلا؛ تعلق، امنیت، جایی که برمی‌گردی |
| **ترازو** — شاهین با دو کفه، آویخته از زیر بام | حرفهٔ وکالت؛ عدالت زیر همان سقف |
| **فنجان قهوه** — در قلب خانه | کافه؛ گفت‌وگو، مکث، هم‌نشینی |

ترتیب عمودی عمدی است: بام بالا، ترازو وسط، فنجان پایین. چشم از بالا به پایین
می‌خواند و همان روایت را می‌گیرد — سرپناه، عدالت، گفت‌وگو.

### ویژگی‌های فنی

| ویژگی | مقدار |
| --- | --- |
| فرمت | SVG، مسیرهای خطی (stroke) |
| viewBox | `0 0 64 64` |
| ضخامت خط | `3.3` (نسبت به viewBox 64) |
| `stroke-linecap` / `linejoin` | `round` |
| تعداد مسیر | ۹ |
| منبع | `src/lib/brand.ts` |

**خطی، نه توپر.** در اندازه‌های کوچک توپر به لکه تبدیل می‌شود؛ خطی هویتش را نگه
می‌دارد. همچنین با وزن‌های فونت Vazirmatn هم‌خوان‌تر است.

### یک منبع، همهٔ خروجی‌ها

```
src/lib/brand.ts  (LOGO_PATHS)
   ├── src/components/ui/Logo.tsx      ← لوگوی داخل سایت
   └── scripts/generate-brand-assets.mjs
         ├── public/favicon.svg
         ├── public/icons/favicon-32.png
         ├── public/icons/apple-touch-icon.png   (180×180)
         ├── public/icons/icon-192.png
         ├── public/icons/icon-512.png
         ├── public/icons/icon-maskable-512.png
         └── public/og-image.jpg                 (1200×630)
```

برای بازسازی همه: `npm run brand`

**هرگز فایل‌های تولیدشده را دستی ویرایش نکنید.** مسیرها را در `brand.ts` عوض کنید و
اسکریپت را اجرا کنید — وگرنه نسخه‌ها از هم جدا می‌افتند.

### حالت‌های مجاز

| حالت | کاربرد | کد |
| --- | --- | --- |
| کامل روی روشن | هدر صفحات داخلی، اسناد چاپی | `<Logo />` |
| کامل روی تیره | هدر شفاف روی قهرمان، فوتر | `<Logo light />` |
| فقط نشانه | favicon، آیکون اپ، آواتار | `<LogoMark />` |

### حریم امن

> **فضای خالی اطراف نشانه = یک‌چهارم ارتفاع نشانه**

```
┌─────────────────────────┐
│       ↕ h/4             │
│    ┌───────────┐        │
│ ←→ │  نشانه    │ ←→     │   h/4 در هر چهار جهت
│h/4 │    (h)    │  h/4   │
│    └───────────┘        │
│       ↕ h/4             │
└─────────────────────────┘
```

هیچ متن، تصویر، خط یا لبه‌ای وارد این محدوده نمی‌شود.

### حداقل اندازه

| محیط | حداقل |
| --- | --- |
| نمایشگر | **۲۴ پیکسل** ارتفاع نشانه |
| چاپ | **۸ میلی‌متر** |
| لوگوی کامل با متن روی نمایشگر | **۱۲۰ پیکسل** عرض |

زیر این اندازه‌ها فنجان و کفه‌های ترازو در هم می‌روند. فقط `<LogoMark />` را
استفاده کنید.

### ⛔ ممنوعیت‌ها

| نکنید | چرا |
| --- | --- |
| کشیدن یا فشردن نامتناسب | نسبت‌ها بخشی از هویت‌اند |
| چرخاندن | نشانه همیشه قائم است |
| تغییر ضخامت خط | با وزن تایپوگرافی هماهنگ شده |
| رنگ‌آمیزی دلخواه | فقط سرمه‌ای، طلایی، سفید |
| گرادیان یا سایه | طراحی عمداً تخت است |
| گذاشتن روی تصویر شلوغ | یا لایهٔ تیره بگذارید یا جای خلوت انتخاب کنید |
| جدا کردن اجزا | ترازو یا فنجان به‌تنهایی معنا ندارند |
| بازکشیدن دستی | همیشه از `brand.ts` |

## ۲. رنگ

### پالت اصلی

| نام | Hex | توکن | نقش |
| --- | --- | --- | --- |
| **سرمه‌ای** | `#0B1F3A` | `navy-900` | رنگ اصلی برند؛ هدر، فوتر، پس‌زمینهٔ قهرمان |
| **طلایی** | `#C9A227` | `gold-500` | تأکید و اقدام؛ دکمهٔ اصلی، خط زیر عنوان |
| **خاکستری روشن** | `#F5F6F8` | `mist-100` | پس‌زمینهٔ بخش‌های متناوب |
| **قهوه‌ای** | `#7B4B2A` | `coffee-500` | فقط برای اشاره به کافه |

**قاعدهٔ نسبت:** تقریباً ۶۰٪ خنثی (سفید/خاکستری) · ۳۰٪ سرمه‌ای · ۱۰٪ طلایی.

طلایی اگر زیاد شود ارزان به نظر می‌رسد. جای درستش: یک دکمهٔ اصلی در هر بخش،
خط تزئینی زیر عنوان، و آیکون‌های کوچک.

### سایه‌های کامل

هر رنگ یک مقیاس دارد که برای حالت‌های hover، حاشیه و پس‌زمینهٔ کم‌رنگ به‌کار می‌رود:

```
navy    950 · 900 · 800 · 700 · 600 · 500
gold    700 · 600 · 500 · 400 · 300 · 200 · 100
mist     50 · 100 · 200 · 300 · 400
coffee  950 · 900 · 700 · 500 · 300 · 100
```

مقادیر دقیق در `tailwind.config.ts`.

### رنگ‌های معنایی (روشن/تاریک خودکار)

این‌ها مقدار ثابت ندارند؛ از متغیرهای CSS می‌آیند و با کلاس `.dark` عوض می‌شوند:

| توکن | نقش |
| --- | --- |
| `surface` | پس‌زمینهٔ اصلی صفحه |
| `surface-2` | بخش متناوب |
| `surface-3` | کارت روی بخش متناوب |
| `ink` | متن اصلی |
| `ink-muted` | متن کمکی |
| `ink-faint` | متن کم‌اهمیت، برچسب |
| `line` | حاشیه و جداکننده |

**همیشه از این‌ها استفاده کنید، نه از `text-gray-500` یا `bg-white`.** فقط این‌طور
حالت تاریک بدون کار اضافه درست می‌ماند.

### کنتراست

همهٔ ترکیب‌های استفاده‌شده حداقل **WCAG AA** را دارند:

| ترکیب | نسبت | سطح |
| --- | --- | --- |
| `navy-900` روی سفید | ۱۵٫۸:۱ | AAA |
| سفید روی `navy-900` | ۱۵٫۸:۱ | AAA |
| `navy-900` روی `gold-500` | ۷٫۲:۱ | AAA |
| `gold-700` روی سفید | ۴٫۹:۱ | AA |
| `ink-muted` روی `surface` | ≥ ۴٫۶:۱ | AA |

> ⚠️ **طلایی روی سفید برای متن ممنوع است.** `gold-500` روی سفید فقط ۲٫۳:۱ است.
> برای متن طلایی روی زمینهٔ روشن از `gold-700` استفاده کنید.

## ۳. تایپوگرافی

### فونت: وزیرمتن (Vazirmatn)

| ویژگی | مقدار |
| --- | --- |
| نوع | متغیر (variable)، وزن ۱۰۰ تا ۹۰۰ |
| میزبانی | خودمیزبان در `src/fonts/` |
| فرمت | woff2 |
| حجم | ۴۶ KB (زیرمجموعهٔ عربی) + ۳۴ KB (لاتین، تنبل) |
| پروانه | SIL OFL 1.1 |

**چرا وزیرمتن:** بهترین فونت آزاد فارسی برای وب. نسخهٔ متغیرش یک فایل است برای همهٔ
وزن‌ها، ارقام فارسی دارد، و در اندازهٔ کوچک روی موبایل خوانا می‌ماند.

**چرا خودمیزبان و نه CDN:** یک دامنهٔ سوم روی مسیر بحرانی حذف می‌شود، حالت آفلاین PWA
کار می‌کند، و هیچ درخواستی به بیرون نمی‌رود.

### مقیاس اندازه

| سطح | موبایل | دسکتاپ | وزن |
| --- | --- | --- | --- |
| عنوان قهرمان | ۳۲px | ۵۴px | ۹۰۰ |
| `h1` صفحه | ۳۰px | ۴۸px | ۹۰۰ |
| `h2` بخش | ۲۴px | ۳۶px | ۹۰۰ |
| `h3` کارت | ۱۸px | ۲۰px | ۸۰۰ |
| متن اصلی | ۱۴px | ۱۶px | ۴۰۰ |
| متن کمکی | ۱۲px | ۱۳px | ۴۰۰ |
| برچسب و ریزمتن | ۱۱px | ۱۱px | ۷۰۰ |

### ارتفاع خط

فارسی به‌خاطر کشیدگی و نقطه‌ها نفس بیشتری از لاتین می‌خواهد:

| نوع متن | ارتفاع خط |
| --- | --- |
| عنوان‌های بزرگ | ۱٫۳۵ – ۱٫۵ |
| متن پاراگراف | **۲٫۰ – ۲٫۱** |
| متن کمکی | ۱٫۹ |

> عدد ۲٫۰ برای متن فارسی سخاوتمندانه به نظر می‌رسد ولی نیست. با ۱٫۵ متن فارسی
> خفه می‌شود.

### وزن‌ها

| وزن | کاربرد |
| --- | --- |
| ۴۰۰ | متن پاراگراف |
| ۵۰۰ | برچسب فرم |
| ۷۰۰ | تأکید درون متن، ریزعنوان |
| ۸۰۰ | عنوان کارت، دکمه |
| ۹۰۰ | عنوان بخش و صفحه |

**از وزن ۱۰۰ تا ۳۰۰ استفاده نکنید** — روی نمایشگر معمولی محو می‌شوند و کنتراست را
می‌شکنند.

### ارقام

**همیشه فارسی.** تابع `toFa()` در `src/lib/utils.ts`:

```tsx
{toFa(1405)}              // ۱۴۰۵
{formatToman(2400000)}    // ۲٬۴۰۰٬۰۰۰
```

استثنا: مقادیر فنی که باید کپی شوند (شمارهٔ تلفن در `href="tel:"`، کد پیگیری در
ورودی فرم).

### جهت متن

کل سایت `dir="rtl"` است. نکات:

- برای فاصله‌گذاری از `ms-*` / `me-*` استفاده کنید، نه `ml-*` / `mr-*`
- پیکان «ادامه» در RTL به **چپ** اشاره می‌کند (`ArrowLeft`)
- اعداد و متن لاتین درون جملهٔ فارسی خودکار LTR می‌شوند — دست نزنید
- نیم‌فاصله (ZWNJ) در واژه‌های مرکب: «می‌شود» نه «می شود»

## ۴. اجزای رابط

### دکمه

شش حالت، همه با حداقل ارتفاع ۴۴ پیکسل (استاندارد لمسی WCAG 2.5.5):

| حالت | کاربرد |
| --- | --- |
| `gold` | اقدام اصلی — **فقط یکی در هر صفحه** |
| `navy` | اقدام ثانویهٔ مهم |
| `outline` | اقدام سوم، فیلترها |
| `light` | روی پس‌زمینهٔ تیره |
| `ghost` | کم‌اهمیت‌ترین |
| `danger` | حذف و لغو |

سه اندازه: `sm` (۴۴px) · `md` (۴۸px) · `lg` (۵۶px)

### گردی گوشه‌ها

| اندازه | کاربرد |
| --- | --- |
| `rounded-xl` (۱۲px) | دکمه، ورودی |
| `rounded-2xl` (۱۶px) | کارت کوچک، نشان |
| `rounded-3xl` (۲۴px) | کارت اصلی |
| `rounded-[2rem]` (۳۲px) | قاب تصویر بزرگ |
| `rounded-full` | آواتار، چیپ، نشانگر |

### سایه

| نام | کاربرد |
| --- | --- |
| `shadow-soft` | کارت در حالت عادی |
| `shadow-lift` | کارت هنگام hover |
| `shadow-gold` | فقط دکمهٔ طلایی |
| `shadow-inset` | فیلد فرو رفته |

سایه‌ها رنگ سرمه‌ای دارند، نه سیاه — سایهٔ سیاه روی زمینهٔ روشن کثیف به نظر می‌رسد.

### فاصله‌گذاری

مقیاس ۴ پیکسلی Tailwind. فاصله‌های پرکاربرد:

| جا | مقدار |
| --- | --- |
| فاصلهٔ عمودی بین بخش‌ها | `section-space` (۶۴px موبایل / ۹۶px دسکتاپ) |
| پدینگ داخل کارت | ۲۴px |
| فاصلهٔ بین کارت‌ها در گرید | ۱۶ – ۲۴px |
| عرض بیشینهٔ محتوا | ۱۲۴۰px (`container-shell`) |
| عرض بیشینهٔ متن خوانا | ۶۸ نویسه (`max-w-prose`) |

## ۵. حرکت

### قاعدهٔ اول

> **هر حرکتی باید `prefers-reduced-motion` را رعایت کند.**

```tsx
className="transition-transform motion-reduce:transition-none motion-reduce:transform-none"
```

### مدت و منحنی

| نوع | مدت | منحنی |
| --- | --- | --- |
| hover و focus | ۱۵۰ – ۳۰۰ms | `ease-out` |
| ظاهر شدن با اسکرول | ۵۰۰ms | `ease-out` |
| باز/بسته شدن آکاردئون | ۳۰۰ms | `ease-in-out` |
| باز شدن پنجرهٔ مودال | ۲۰۰ms | `ease-out` |

هیچ حرکتی بیش از ۶۰۰ میلی‌ثانیه طول نمی‌کشد.

### ⛔ هیچ کتابخانهٔ انیمیشنی

`framer-motion` حذف شد چون ۳۴KB به مسیر بحرانی اضافه می‌کرد. جایگزین‌ها:

| کاربرد | ابزار |
| --- | --- |
| ظاهر شدن با اسکرول | `IntersectionObserver` — کامپوننت `Reveal` |
| شمارندهٔ عددی | `requestAnimationFrame` — کامپوننت `CountUp` |
| آکاردئون | `grid-template-rows: 0fr → 1fr` |
| ورود اولیه | `animate-fade-up` / `animate-fade-in` |

فقط `transform` و `opacity` را متحرک کنید. `width`، `height`، `top` و `margin`
باعث بازچینش صفحه می‌شوند و روی موبایل می‌لنگند.

## ۶. حالت تاریک

با کلاس `.dark` روی `<html>` کار می‌کند و همهٔ متغیرهای CSS را عوض می‌کند.

| جنبه | جزئیات |
| --- | --- |
| فعال‌سازی | دکمهٔ `ThemeToggle` در هدر |
| ذخیره | `localStorage` (تنها چیزی که سایت ذخیره می‌کند) |
| پیش‌فرض | `prefers-color-scheme` سیستم کاربر |
| جلوگیری از پرش | اسکریپت درون‌خطی در `<head>` پیش از اولین رنگ‌آمیزی |
| `theme-color` | روشن `#0B1F3A` · تاریک `#081426` |

### قواعد

- هرگز `bg-white` یا `text-gray-900` ننویسید — از `bg-surface` و `text-ink`
- تصاویر در حالت تاریک کم‌رنگ نمی‌شوند؛ به‌جایش لایهٔ تیره روی آن‌ها
- طلایی در حالت تاریک به `gold-400` می‌رود تا کنتراست حفظ شود
- سایه‌ها در حالت تاریک تقریباً نامرئی‌اند — از حاشیه به‌جایشان

- [ ] همهٔ متن‌ها از توکن‌های `ink*` می‌آیند، نه رنگ ثابت
- [ ] ارتفاع خط پاراگراف‌ها ≥ ۲٫۰
- [ ] همهٔ ارقام با `toFa()` فارسی شده‌اند
- [ ] هر عنصر قابل لمس ≥ ۴۴×۴۴ پیکسل
- [ ] هر تصویر `alt` توصیفی دارد
- [ ] در حالت تاریک هم بررسی شده
- [ ] در عرض ۳۲۰px نمی‌شکند
- [ ] هر حرکت `motion-reduce` دارد
- [ ] حریم امن لوگو رعایت شده
