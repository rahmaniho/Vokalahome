## ۲) قواعد ثابت پروژه

1. **هیچ آدرس مطلقی در کد نوشته نمی‌شود.** همه از `withBase()` / `absoluteUrl()` در `src/lib/site.ts` می‌گذرد.
2. **تغییر دامنه در آینده = تغییر دو متغیر محیطی** (`NEXT_PUBLIC_SITE_ORIGIN`, `NEXT_PUBLIC_BASE_PATH`) و نه بازنویسی کد.
3. هیچ وابستگی به سرور اختصاصی؛ فرم‌ها از طریق Formspree/Supabase (اختیاری) یا fallback واتساپ.
4. بودجه عملکرد: JS اولیه صفحه نخست زیر ۱۲۰ kB، هر تصویر زیر ۲۰۰ kB.

| سنجه | پیش | پس |

| JS اولین بارگذاری صفحهٔ نخست | ۱۵۸ kB | **۱۱۳ kB** |

| فونت روی مسیر بحرانی | ۸۱ kB | **۴۶ kB** |
| صفحات پیش‌رندرشده | ۳۵ | **۵۱** |
| آدرس در نقشهٔ سایت | ۱۱ (دستی) | **۴۷ (خودکار)** |
| فرمت تصویر | JPEG | **AVIF + WebP + JPEG** |
| PWA | ندارد | **نصب‌شدنی، با حالت آفلاین** |
| حالت تاریک | ندارد | **دارد، بدون پرش** |
| لینک شکستهٔ داخلی | — | **۰ در ۵۰ صفحه** |

بودجهٔ عملکرد (JS اولیه زیر ۱۲۰ kB) رعایت شد: **۱۱۳ kB**.

### باگ‌هایی که در مسیر پیدا و رفع شدند

| باگ | اثر |
| --- | --- |
| `canonical` روی دامنهٔ غیرفعال `vokalahome.com` | گوگل صفحات را به آدرسی که وجود ندارد نسبت می‌داد |
| صفحهٔ بارگذاری مصنوعی با ۸۵۰ms تأخیر | مستقیماً LCP را عقب می‌انداخت |
| سبک درون‌خطی `aspectRatio` که کلاس `aspect-*` را خنثی می‌کرد | ۹ فراخوانی `Picture` نسبت ابعاد اشتباه داشتند |
| `prebuild`/`postbuild` دو بار اجرا می‌شدند | قلاب خودکار npm + صدا زدن دستی در اسکریپت `build` |
| هر دو زیرمجموعهٔ فونت preload می‌شدند | ۳۴ kB اضافه روی مسیر بحرانی هر صفحه |
| `aria-pressed` روی `role="gridcell"` | ویژگی نامعتبر در تقویم شمسی |
| Fragment بدون کلید داخل `<tbody>` | هشدار React در جدول مقایسهٔ پلن‌ها |
