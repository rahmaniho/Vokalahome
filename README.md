# خانه وکیل — وب‌سایت استاتیک مؤسسه حقوقی

وب‌سایت فارسی، RTL و استاتیک «خانه وکیل» با Next.js 14، TypeScript، Tailwind CSS و Framer Motion. خروجی پروژه برای GitHub Pages به‌صورت کامل در پوشه `out` تولید می‌شود.

## اجرا

```bash
npm install
npm run dev
```

ساخت نسخه انتشار:

```bash
npm run typecheck
npm run build
```

## امکانات

- صفحه اصلی کامل با انیمیشن، آمار، خدمات، تیم، مقالات، نظرات و CTA
- صفحات درباره ما، خدمات و جزئیات، وکلا و پروفایل، مقالات، FAQ، مشاوره و تماس
- تقویم شمسی تعاملی و اسلات‌های نیم‌ساعته
- ذخیره رزرو آزمایشی در `localStorage` و کد رهگیری سمت کاربر
- فرم‌های آماده اتصال به Formspree
- متادیتا، Schema، sitemap، robots و Open Graph
- Custom cursor، نوار پیشرفت اسکرول و منوی شناور سریع
- رعایت `prefers-reduced-motion` و ناوبری صفحه‌کلید
- GitHub Actions برای انتشار خودکار Pages

## مواردی که پیش از انتشار نهایی باید تکمیل شوند

تمام داده‌های نامشخص در `src/lib/constants.ts` و فایل‌های `src/lib/data/` متمرکز شده‌اند و با `[___]` یا متن توضیحی مشخص‌اند:

1. شناسه واقعی Formspree به‌جای `YOUR_FORM_ID`
2. پلاک و واحد نشانی دفتر و مختصات دقیق نقشه
3. شماره پروانه وکالت و مدارک مدیر
4. تصویر رسمی علی کشاورز نجفی؛ تصویر فعلی AI-generated و صرفاً پیشنهاد بصری است
5. نام، تصویر، بیوگرافی و شماره پروانه اعضای تیم
6. تعرفه‌های مصوب مشاوره
7. تلفن و واتساپ نهایی (شماره‌های فعلی داده‌شده در بریف)
8. بررسی تقویم تعطیلات رسمی هر سال

## انتشار GitHub Pages

Workflow موجود در `.github/workflows/deploy.yml` با هر Push به `main` یا شاخه Arena اجرا می‌شود. در تنظیمات مخزن:

1. Settings → Pages
2. Source را روی **GitHub Actions** قرار دهید.
3. دامنه `khanevokala.com` را به‌عنوان Custom domain ثبت کنید.
4. DNS را مطابق مستندات GitHub Pages تنظیم و سپس Enforce HTTPS را فعال کنید.

فایل `public/CNAME` در خروجی حفظ می‌شود.
