# خانه وکلا — Vokala House

باشگاه تخصصی و کافه حقوقی وکلا: فضایی که وکلا در آن می‌نشینند، قهوه می‌نوشند، دانش حقوقی مبادله می‌کنند، در نشست‌های علمی شرکت می‌کنند و در اتاق‌های مجهز با موکلان خود جلسه می‌گذارند.

## مدل کسب‌وکار سایت

| موضوع | اعضا | غیراعضا |
| --- | --- | --- |
| اتاق‌های مشاوره | رایگان (در سقف ساعتی پلن) | ساعتی ۵۰۰٬۰۰۰ تومان |
| نشست‌های علمی | رایگان / با تخفیف | از ۳۰۰٬۰۰۰ تومان |
| کافه و سالن مطالعه | دسترسی نامحدود + تخفیف منو | ورود آزاد، منوی عادی |

پلن‌های عضویت: **کارآموزی**، **وکالت**، **دفتر مجازی** (`src/lib/data/plans.ts`).

## ساختار

```
src/app/            صفحات (خانه، درباره، امکانات، عضویت، اتاق‌ها، رویدادها، وکلای عضو، دانش‌نامه، مشاوره، تماس، صفحات حقوقی)
src/components/     کامپوننت‌های چیدمان، کارت‌ها، فرم‌ها و بخش‌های تعاملی
src/lib/data/       داده‌های محتوایی: plans, rooms, events, services (امکانات), lawyers, articles, faqs
src/lib/constants.ts  اطلاعات تماس، منو، تعرفه اتاق (ROOM_RATE)
```

## اجرا

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # خروجی استاتیک در out/ (output: export)
npm run typecheck
```

سایت به‌صورت استاتیک برای GitHub Pages با `basePath: /Vokalahome` ساخته می‌شود.

## موارد نیازمند تکمیل پیش از انتشار

- نشانی دقیق، شماره تماس، ایمیل و شبکه‌های اجتماعی در `src/lib/constants.ts`
- `formspreeEndpoint` برای فعال شدن ارسال واقعی فرم‌ها
- پروفایل و تصویر وکلای عضو در `src/lib/data/lawyers.ts`
- تاریخ و سخنران رویدادها در `src/lib/data/events.ts`
- تصاویر واقعی کافه و اتاق‌ها به‌جای تصاویر پیشنهادی در `public/images/`
